# dsh-annotate

对 AI 刚做出来的成品（图 / 文档 / 一段话）**直接用鼠标指出哪里不满意**，每处配一句话要求，点「发送批注」就把整份清单整理成结构化文字插进对话输入框——它就是下一轮的修改指令。

批注**只作指令用**：不写回源软件，不画进成品图，也不进成品本身，更不落盘（纯浏览器内存，刷新即清）。

## 怎么用

1. 聊天输入框右侧点「批注」，清单就浮在这个按钮**正上方**（向上展开，不挡输入框）。
2. 三处都能批注：
   - **对话里的文字**：选中 → 浮出「＋ 批注」
   - **对话里的图片**：点图上不满意的位置 → 浮出「＋ 批注」（记下归一化坐标，如 `43%, 99%`）
   - **右侧面板里的内容**（文档 / 图片预览）：选中或点图，同上
   - **PDF / 文档预览**：预览右上角有常驻的「＋ 批注」角标，点它即批注这块预览（PDF 自带阅读器是独立框架，指针进去后页面收不到点击，只能走角标）
3. 弹框里写一句话要求，`保存批注`（要求为空时按钮禁用，**不会有没要求的批注**）。`Esc` 取消，`Ctrl/Cmd+Enter` 保存。
4. 清单里逐条勾选 / 取消勾选 / `×` 删除。
5. 底部 `发送批注（N 条）`：只把**已勾选**的条目拼成结构化文字，追加到当前草稿后面（已有草稿不动）。

发送出去的格式：

```
请按下面 2 条批注修改：
1. [对话文字]：这段结论太笼统
   要求：换成具体数值
2. [对话图片] 位置 43%, 99%：图1
   要求：把图例挪到左边
```

## 数据结构

一条批注就七个扁平字段，没有嵌套：

```js
{ id, kind: "text" | "image" | "panel", ref, x, y, note, on }
```

`x` / `y` 只有 `kind === "image"` 才有值（0~1 归一化），`on` 是勾选状态。

## 边界

- 面板是插件自己的 fixed 块（宿主右栏 tab 种类由控制器持有，插件加不了 tab），直接挂在 `document.body` 上——输入框插槽被卸载重挂、右栏开合都不会影响清单数据与渲染。位置每次按「批注」按钮的 `getBoundingClientRect` 重算（`bottom = innerHeight - rect.top + 8`），按钮拿不到才退回右下角。
- 只在点到「有内容的东西」时才给批注入口：图片 > 输入框外的文字选区 > `iframe` / `embed` / `object` / `canvas` 预览容器。空白处点击不弹。
- PDF / 文档预览常包在 `iframe`（浏览器自带阅读器）或 `embed` 里，指针进去之后父文档收不到 `mouseup`，所以给每块可见预览挂一个 22px 的常驻角标（`MutationObserver` + `scroll` / `resize` 跟随定位）。角标只覆盖预览右上角一小块，不挡滚动。
- 「侧栏面板 / 对话」的归属靠几何分栏判断（`window.innerWidth * 0.62`），只是个来源标签，不影响能不能批注。
- 不替换 `conversation.chat.*` 这些 shipped UI 槽，纯事件委托，卸载即净。
